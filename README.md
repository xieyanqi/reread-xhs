# 拾读 · 小红书收藏复读

## 安装

1. 解压 ZIP，找到包含 `manifest.json` 的 `reread-xhs` 文件夹。
2. 用桌面版 Chrome 116 或更新版本打开 `chrome://extensions`。
3. 打开右上角「开发者模式」，点「加载已解压的扩展程序」，选中上述文件夹。
4. 在浏览器的扩展程序菜单里固定「拾读」，方便从任意小红书页面打开侧栏。

## 开始使用

1. **收录收藏。** 用网页版小红书打开个人主页的收藏列表，滚动到想导入的范围，点击工具栏里的拾读图标，再点「导入当前小红书页面」。也可以打开单篇原帖再导入，或粘贴多条帖子链接或分享文本。导入读取当前页面呈现的帖子链接，能识别的标题会一起保存。原帖地址保留访问参数。
2. **回到原帖复读。** 在「待复读」点「打开原帖」，然后选择写一条自己的笔记、记一个下一步行动，或归档。笔记和行动默认一周后回看，日期可改。
3. **到期回看。** 「待回看」显示今天到期和逾期的条目，工具栏图标显示数量。Chrome 运行并允许系统通知时，在有到期条目的日子里，拾读最多推送一次提醒。关机或退出期间错过的检查会在 Chrome 下次启动时补做。
4. **留下结果。** 每次复盘选择「有进展」「卡住了」或「已完成」，写一句记录。有进展或卡住的条目要安排下次回看，完成后停止提醒。「全部」保留回看历史。

## 数据和适用范围

- 收藏链接、笔记和复盘记录保存在 Chrome 当前用户配置文件，不发送给服务器。可用「导出 Markdown」带走记录。卸载扩展会清除扩展的数据。
- 导入依赖网页版已加载的帖子链接。小红书页面如果改版、收藏未加载或访问受限，可打开单篇帖子或直接粘贴分享链接。不同的短分享链接可能指向同一帖子，在未打开原帖前会分别收录。
- 图文或视频请从原帖阅读。独立窗口适合整理已收录的帖子，也可以粘贴链接。浏览器通知只依赖你输入的日期和复盘状态。
