## 安装

1. 解压 ZIP，找到包含 `manifest.json` 的 `reread-xhs` 文件夹。
2. 用桌面版 Chrome 116 或更新版本打开 `chrome://extensions`。
3. 打开右上角「开发者模式」，点「加载已解压的扩展程序」，选中上述文件夹。
4. 在浏览器的扩展程序菜单里固定「拾读」，方便从任意小红书页面打开侧栏。

## 从旧版更新

将新版文件覆盖到当初选择的原扩展文件夹，在 `chrome://extensions` 中点击「拾读」卡片上的圆形箭头重新加载。用原文件夹更新可继续使用已有记录。新版需要 Chrome 允许拾读访问小红书网页。如果 Chrome 收回了网站访问权限，请在小红书网页上右键点「拾读」的工具栏图标，在「可以读取和更改网站数据」里选择允许在小红书网站访问，然后刷新网页。

## 开始使用

1. **收录收藏。** 打开网页版小红书的「我的主页 → 收藏 → 笔记」，在拾读侧栏点「从头扫描收藏」。只想添加个别帖子时，可以展开「粘贴链接」，输入原帖链接或分享文本。
2. **回到原帖复读。** 在「待复读」点「打开原帖」，然后选择写一条自己的笔记、记一个下一步行动，或归档。笔记和行动默认一周后回看，日期可改。
3. **到期回看。** 「待回看」显示今天到期和逾期的条目，工具栏图标显示数量。Chrome 运行并允许系统通知时，在有到期条目的日子里，拾读最多推送一次提醒。关机或退出期间错过的检查会在 Chrome 下次启动时补做。
4. **留下结果。** 每次复盘选择「有进展」「卡住了」或「已完成」，写一句记录。有进展或卡住的条目要安排下次回看，完成后停止提醒。「全部」保留回看历史。

## 收藏对账

在「我的主页 → 收藏 → 笔记」点击「从头扫描收藏」，拾读在当前收藏标签页中读取从开头已加载的收藏，然后逐页接着读。保持该标签页打开即可暂停和继续。收藏页刷新后会先恢复到上次已读的位置并核对边界。标签页关闭或列表顺序变更时，可以从头重扫，已收录的内容按帖子 ID 去重。

对账区显示网站笔记总数、已确认的不同帖子数及剩余差额。「导出对账 CSV」按网站返回顺序记录每条笔记的标题、ID、原帖和收录状态。站点停止分页时，差额保留在界面上；网站没有返回的帖子无法逐条列出。已收录的条目也可以按标题或 ID 搜索。

## 整理收藏

从侧栏或独立窗口点击「整理收藏」。

1. **过期信息。** 筛出标题注明完整日期且已经过期的活动、优惠和报名通知。先打开原帖确认是否还有参考价值。
2. **按主题。** 用标题关键词在本地分组，显示每组数量和三条代表笔记。选择「看一下可清理的」进入候选列表。可逐条保留、处理，也可以勾选批量处理。批量勾选会跳过已经写了笔记或设了行动的条目。
3. **逐条看。** 每轮最多 20 条，可以保留、待清理或跳过。整轮看完后再核对名单。

执行前可从名单逐条取消勾选，并选择只移出拾读，或同时取消小红书收藏。取消收藏按条确认，遇到失败会停止并保留尚未完成的条目。

打开原帖或取消收藏遇到 Chrome 错误页时，会在同一标签页尝试备用原帖地址，并保留原链接的访问参数。若仍无法连接，拾读不会把该条目标记为已取消。

## 取消收藏并移出复读

在侧栏点击对应卡片上的「取消收藏并移出」。如果原帖已经在浏览器里打开，拾读会直接使用已有的标签页，并在原标签页刷新核对。原帖没有打开时，会临时新开一个原帖标签页，确认成功后自动关闭。失败时会保留标签页并提示卡住的步骤。原帖已是未收藏时，会直接移出复读。若原帖无法访问或状态不明确，条目会保留。取消成功后，已经写过的笔记、行动和历史会留在「全部」，并停止到期提醒。

旧版误导入的记录可以用同一个按钮处理。拾读会跳过之后批量读取到的已移出条目，防止还没刷新的收藏页把它们加回来。如果你重新收藏，可粘贴原帖链接手动添加。

## 数据和适用范围

- 收藏链接、笔记和复盘记录保存在 Chrome 当前用户配置文件，不发送给服务器。可用「导出 Markdown」带走记录。卸载扩展会清除扩展的数据。
- 「从头扫描收藏」使用网页版自身的分页。个别帖子可以使用「粘贴链接」手动收录。不同的短分享链接可能指向同一帖子，在未打开原帖前会分别收录。
- 图文或视频请从原帖阅读。独立窗口适合整理已收录的帖子，也可以粘贴链接。浏览器通知只依赖你输入的日期和复盘状态。
