# 拾读 · 小红书收藏复读

每个发布版本都有独立的 Git 标签。遇到的问题、对应改动和验证情况见[更新日志](CHANGELOG.md)。

## 安装

1. 解压 ZIP，找到包含 `manifest.json` 的 `reread-xhs` 文件夹。
2. 用桌面版 Chrome 116 或更新版本打开 `chrome://extensions`。
3. 打开右上角「开发者模式」，点「加载已解压的扩展程序」，选中上述文件夹。
4. 在浏览器的扩展程序菜单里固定「拾读」，方便从任意小红书页面打开侧栏。

## 从旧版更新

将新版文件覆盖到当初选择的原扩展文件夹，在 `chrome://extensions` 中点击「拾读」卡片上的圆形箭头重新加载。用原文件夹更新可继续使用已有记录。新版需要 Chrome 允许拾读访问小红书网页。如果 Chrome 收回了网站访问权限，请在小红书网页上右键点「拾读」的工具栏图标，在「可以读取和更改网站数据」里选择允许在小红书网站访问，然后刷新网页。

## 开始使用

1. **收录收藏。** 用网页版小红书打开个人主页的收藏列表，滚动到想导入的范围，点击工具栏里的拾读图标，再点「导入当前小红书页面」。也可以打开单篇原帖再导入，或粘贴多条帖子链接或分享文本。批量导入从「收藏 → 笔记」读取已加载的收藏，能识别的标题会一起保存。原帖地址保留访问参数。每次导入都会显示识别数、新增数及已收录数，滚动后可再次点击。
2. **回到原帖复读。** 在「待复读」点「打开原帖」，然后选择写一条自己的笔记、记一个下一步行动，或归档。笔记和行动默认一周后回看，日期可改。
3. **到期回看。** 「待回看」显示今天到期和逾期的条目，工具栏图标显示数量。Chrome 运行并允许系统通知时，在有到期条目的日子里，拾读最多推送一次提醒。关机或退出期间错过的检查会在 Chrome 下次启动时补做。
4. **留下结果。** 每次复盘选择「有进展」「卡住了」或「已完成」，写一句记录。有进展或卡住的条目要安排下次回看，完成后停止提醒。「全部」保留回看历史。

## 取消收藏并移出复读

在侧栏点击对应卡片上的「取消收藏并移出」。拾读会临时打开原帖标签页，读取收藏状态；确认已收藏时，点击小红书原帖的收藏按钮并重新加载核对。原帖已是未收藏时，会直接移出复读。若原帖无法访问或状态不明确，条目会保留。取消成功后，已经写过的笔记、行动和历史会留在「全部」，并停止到期提醒。

旧版误导入的记录可以用同一个按钮处理。拾读会跳过之后批量读取到的已移出条目，防止还没刷新的收藏页把它们加回来。如果你重新收藏，可打开单篇原帖重新导入，或粘贴原帖链接。

## 数据和适用范围

- 收藏链接、笔记和复盘记录保存在 Chrome 当前用户配置文件，不发送给服务器。可用「导出 Markdown」带走记录。卸载扩展会清除扩展的数据。
- 插件只会在你点「导入当前小红书页面」时读取当前小红书标签页。导入依赖网页版已加载的帖子。小红书页面如果改版、收藏未加载或访问受限，可打开单篇帖子或直接粘贴分享链接。不同的短分享链接可能指向同一帖子，在未打开原帖前会分别收录。
- 图文或视频请从原帖阅读。独立窗口适合整理已收录的帖子，也可以粘贴链接。浏览器通知只依赖你输入的日期和复盘状态。
